# Glow Crossing

An original neon arcade crossing game. Guide **Lumi the axolotl** across five lanes of glowing traffic and a river of drifting rafts and sinking lilies, into all five portals.

## Play
Turn on GitHub Pages (Settings → Pages → Deploy from branch → `main` / root), then open:

https://lezkt1811-maker.github.io/frogged/

## Controls
- **Phone:** the 4-direction pad at the bottom, or swipe on the board (tap = hop up)
- **Keyboard:** Arrow keys or WASD · P = pause
- ⏸ pause · 🔊 sound on/off

## Scoring
- +10 for each new row reached
- +50 per portal, plus 2 × seconds left on the timer
- +130 for grabbing the gold **13 star** when it appears in a portal
- +1000 for filling all five portals (the next level gets faster)

All graphics and sounds are generated in code — no outside assets.
